# React Day 6 – Data Rendering

This project contains the four React data-rendering tasks:

1. Primitive Data Rendering
2. Array Rendering using map()
3. Object Rendering
4. Array of Objects using map()

## Run the project

Open the project folder in VS Code or terminal:

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Concepts practiced

- Primitive data
- JSX rendering with `{ }`
- Arrays
- `map()`
- Objects
- Object property access
- Array of objects
- `key` while rendering lists
