REACT BASICS – THEORY TASKS

TASK 1 – REACT BASICS

1. What is React?

React is a JavaScript library used to build user interfaces, especially for web applications. It was developed by Facebook.

2. Why do we use React?

We use React to build fast, interactive and reusable user interfaces. It makes it easier to manage changes in the UI.

3. Is React a library or framework?

React is a JavaScript library, not a complete framework. It mainly focuses on building the user interface.

4. What are the main features of React?

Main features include:
  • Components
  • JSX
  • Virtual DOM
  • Declarative UI
  • Reusable components
  • One-way data flow

5. What is a Single Page Application (SPA)?

A Single Page Application is a web application where the browser loads one main page and updates the required content without completely reloading the page.

6. What is declarative UI?

Declarative UI means we describe what the UI should look like, and React handles how to update the DOM when data changes.

TASK 2 – COMPONENTS

1. What is a Component in React?

A component is a small, independent and reusable part of a React user interface. For example, Navbar, Button and Card can be components.

2. Why do we use Components?

Components help us divide a large UI into smaller parts. They make the code easier to understand, maintain and reuse.

3. What is a Functional Component?

A functional component is a JavaScript function that returns JSX. Example:

function Welcome() { return <h1>Hello</h1>; }

4. What is Component-Based Architecture?

It is an approach where an application is divided into small independent components that work together to create the complete UI.

5. What is a Component Tree?

A component tree shows the relationship between components. A parent component can contain child components.

6. Why should component names start with a capital letter?

React uses the capital letter to distinguish custom components from normal HTML elements. For example, <Navbar /> is treated as a React component.

7. What is a reusable component?

A reusable component is a component that can be used multiple times in different parts of an application.

TASK 3 – JSX

1. What is JSX?

JSX stands for JavaScript XML. It is a syntax that allows us to write HTML-like code inside JavaScript.

2. Why do we use JSX in React?

JSX makes UI code easier to read and allows us to write the structure of the UI close to the JavaScript logic.

3. Is JSX HTML?

No. JSX looks similar to HTML, but it is JavaScript syntax that is transformed into React element creation.

4. How do we write JavaScript expressions inside JSX?

JavaScript expressions are written inside curly braces { }.

Example:
<h1>Hello {name}</h1>

5. Why do we use className instead of class?

In JSX, className is used to specify a CSS class because class is a JavaScript keyword.

6. What is React Fragment?

A React Fragment allows us to group multiple elements without adding an extra HTML element to the DOM.

Example: <>...</>

7. What are the important JSX rules?

Important rules include:
  • Return one parent element or Fragment.
  • Close all tags.
  • Use className instead of class.
  • Use camelCase for many JSX attributes.
  • Use { } for JavaScript expressions.

TASK 4 – DOM, VIRTUAL DOM & RECONCILIATION

1. What is DOM?

DOM stands for Document Object Model. It represents the HTML page as a tree of objects that JavaScript can access and modify.

2. What is Virtual DOM?

The Virtual DOM is a lightweight representation of the UI that React uses to determine what changes are needed in the actual DOM.

3. What is the difference between DOM and Virtual DOM?

The DOM is the actual browser document. The Virtual DOM is a representation used by React to calculate UI changes before updating the browser DOM.

4. What is Reconciliation in React?

Reconciliation is React's process of comparing the previous UI representation with the new one and determining what needs to change in the actual DOM.

5. What is Diffing?

Diffing is the comparison between the previous React element tree and the new React element tree to find the differences.

6. How does React identify changes in the UI?

React compares the previous and new element trees. It uses element types, positions and keys for list items to determine what changed.

7. Why is key important while rendering lists?

A key gives each list item a stable identity. React uses it to efficiently identify which items were added, removed or changed.

1. What is Rendering?

Rendering is the process of React calling a component to determine what UI should be displayed based on its current props and state.

2. What is Re-rendering?

Re-rendering happens when React calls a component again because its state, props or another relevant update has changed.

3. What causes a component to re-render?

Common causes include:
  • State update
  • Props change
  • Parent component re-render
  • Context value change

4. Does re-render mean the complete browser DOM is recreated?

No. A re-render does not mean the entire browser DOM is recreated. React calculates the required changes and updates only the necessary parts of the DOM.

5. What happens during reconciliation?

React compares the previous element tree with the new element tree, identifies the differences and determines the required DOM updates.

6. What is the relationship between Virtual DOM, Diffing and Reconciliation?

The Virtual DOM represents the UI. Diffing compares the old and new representations. Reconciliation uses this comparison to determine the necessary updates to the actual DOM.

7. Explain the React rendering process in your own words.

First, a component returns JSX. React creates a representation of that UI. When state or props change, React renders the component again. It then compares the previous and new UI representations using reconciliation and diffing. Finally, React updates only the required parts of the browser DOM, and the user sees the updated UI.
