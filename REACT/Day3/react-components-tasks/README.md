# React Components Tasks

This single React + Vite project contains all 3 tasks.

## Task 1 - Single Component
- Header.jsx
- Export Header
- Import Header into App.jsx
- Display `<Header />`

## Task 2 - Multiple Components
- Navbar.jsx
- Home.jsx
- About.jsx
- Footer.jsx
- All are imported into App.jsx

## Task 3 - Nested & Reusable Components
- Home imports ProductCard
- ProductCard is displayed 3 times
- Product name and price are passed using props

## Run the project

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.
